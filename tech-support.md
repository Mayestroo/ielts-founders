# Website Support

After your website is delivered, support is included for **3 months**.

During this period, we will help with problems on the current website.

## What is included

- Fixing things that stop working (contact form, pages, buttons, login)
- Keeping the site safe with regular updates
- Checking backups and helping restore the site if needed
- Small text and image changes (up to 2 hours per month)
- Basic checks to make sure the site is online and working normally

## Response time

- Normal issues: reply within **1 working day**
- Urgent issues (site is down): faster help, usually within **4-6 working hours**

## What is not included

- New pages or new features
- Full redesign of the website
- Connecting new outside services (for example, payment tools)
- Costs for paid apps, tools, or subscriptions

## Extra work

If you need anything outside this support list, we can still do it.
We will send a separate price and timeline first.
